# Changelog

## v1.0.0
- Initial release of Rythem ambient learning operating system.
- Add local SQLite database with automated daily snapshots and JSON export/import.
- Introduce Effort Points system (10 minutes = 1 point) and dynamic pacing.
- Add user-driven focus system with self-paced topic pulling.
- Integrate private offline on-device AI models (Qwen 2.5 GGUF) with download manager.
- Add monochrome liquid glass design system with light and dark themes.
- Add Flag Notes notebook in Explore for doubt and concept tracking.
- Add YouTube playlist and video ingestion engine with chapter remapping.

## v1.1.0-Stable
- Add categorized custom study tasks with chronological curriculum appending.
- Add in-app GitHub update checker and APK download manager in Settings.
- Add zero-cloud streak protection for custom study tasks.
- Refine adaptive launcher icon with equal corner padding.

## v1.1.1-preview
- Introduce default Open Lab tracker for independent study and projects.
- Add duration-based effort conversion with preset duration chips.
- Add dynamic user-defined task categories with SQLite persistence.

## v1.1.2-preview
- Add native Android APK installer bridge with install permission prompt.
- Clean up task tile typography and remove redundant front category chips.
- Unify curriculum task tiles within parent chapters.
- Streamline button wording across Flow and task dialogs.

## v1.1.3
- Group tasks by category on top-left of task lists.
- Clean task cards by removing inline tag clutter.
- Fix custom task title visibility and exclude custom tasks from gap detection.

## v1.1.4
- Redesign native in-app installer with Android FileProvider intent.
- Clean up redundant UI text and duplicate screen headers.
- Streamline default tracker layout.

## v1.1.5
- Remove unnecessary gap cards and 30-day countdown from default tracker.
- Streamline text labels across Flow and Explore screens.

## v1.1.6
- Switch offline AI model download URLs to verified Hugging Face CDN mirrors.
- Add automated candidate failover in model download manager.
- Synchronize in-app version to prevent false-positive update alerts.

## v1.1.7
- Audit and simplify global UI text to concise 1–2 word button labels.
- Streamline settings, backup, and restore dialog messages.
- Prevent button text wrapping and improve small-screen card spacing.

## v1.1.8-Stable
- Clean up and consolidate release changelogs from v1.0.0 through v1.1.7.
- Complete verified stable release incorporating all UI simplifications, model downloader fixes, and native updater improvements.

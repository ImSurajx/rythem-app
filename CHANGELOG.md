# Release

## v1.1.9
- **Flag Notes & Friction Deletion**: Added direct delete action on Explore flag note cards, "Remove Flag" action in confusion dialogs, and one-tap reflection clearing in checkpoint dialogs.
- **Global App UI Enhancement**: Overhauled visual aesthetics with electric cyan and amber accent gradients, luminous glowing progress meters, liquid glass cards, and an elevated frosted bottom navigation dock.
- **Enhanced Onboarding Experience**: Redesigned first-launch wizard with dynamic rhythm wave visuals, interactive beat metaphor demonstration ("Beats Over Clocks"), and core self-paced momentum value pillars.
- **Global Terminology Shift to "Beats"**: Unified progress tracking and task weights to "Beats" across metrics, flow screens, checkpoint dialogs, custom tasks, roadmaps, and offline AI mentors.
- **In-Place Backup Engine Replacement**: Overhauled local backup storage to atomically replace and update the master backup file in place, preventing timestamped file clutter and reclaiming storage.
